# Architecture Decision Records (ADRs)

This directory records significant architectural decisions using the
[MADR](https://adr.github.io/madr/) style.

Add a new ADR when you make a decision that is costly to reverse. Number them
sequentially (`NNNN-title.md`) and never delete one — supersede it instead.
